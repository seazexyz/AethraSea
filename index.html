docs / getting-started

Getting Started with AethraSea

Quick installation guide and core deployment overview.

AethraSea is a high-performance Folia/Paper fork focused on finding the perfect balance between multi-threaded performance, vanilla behavior, and stability in high-load Minecraft environments.

System Requirements

  • Java Development Kit (JDK) 21 or higher
  • Multi-core CPU (Recommended 4+ dedicated cores for region thread allocation)
  • 64-bit Linux / Windows Server environment

First Launch

Place aethrasea-paperclip-26.2.jar into an empty directory and execute:

java -Xms4G -Xmx4G -jar aethrasea-paperclip-26.2.jar --nogui

On initial boot, AethraSea will automatically extract libraries and generate the sea.yml configuration file.

docs / faq

Frequently Asked Questions

Common questions regarding compatibility, performance, and plugins.

Is AethraSea compatible with Paper plugins?

AethraSea inherits Folia's regionized multi-threading model. Standard Paper plugins that do not access main-thread singletons without region checks work out of the box or via Folia schedulers.

How does Async Pathfinding help reduce lag?

Pathfinding calculations for entities are dispatched to background thread pools using thread-safe navigation tasks, preventing high mob populations from choking the region tick loop.

docs / jvm-flags

Recommended JVM Flags

Optimized garbage collection parameters for Java 21+.

For high-concurrency regionized workloads with G1GC or ZGC, use the following startup flags:

java -Xms8G -Xmx8G -XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=20 -XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC -jar aethrasea-paperclip-26.2.jar --nogui

docs / api

API Usage Guide

Developing plugins against AethraSea region APIs.

AethraSea exposes region scheduler hooks identical to standard Folia APIs. Always dispatch region-specific entity and block modifications using the appropriate scheduler:

Bukkit.getRegionScheduler().run(plugin, location, task -> {
    // Region-safe execution here
});
